# dsh-multitenant 产品文档

> 版本：1.0 ｜ 更新：2026-09 ｜ 配套代码 commit `823ec16` ~ `3e7f759`

## 1. 产品简介

**dsh-multitenant**（DSH 多租户管理平台）是基于 SWTC 区块链地址体系的智能容器分配系统：任何用户凭钱包即可自助开通一个**专属 DSH 容器实例**，数据完全隔离、按需分配资源、每日限额使用。

一句话：**钱包即身份，容器即空间**——无需注册、无需密码，连接钱包就有自己的 DSH。

## 2. 核心概念

| 概念      | 说明                                                                |
| --------- | ------------------------------------------------------------------- |
| SWTC 地址 | 用户身份，由 CCDAO 浏览器插件管理（钱包）                           |
| 专属容器  | 每个地址一个独立 Docker 容器（内部运行 DSH），端口 31000 起随机分配 |
| 数据卷    | 容器销毁后数据保留；重新连接自动恢复                                |
| 每日限时  | 每个地址每天累计 120 分钟，到点优雅停止（数据保留）                 |
| CWT 验证  | 申请-审批-出示机制；获批地址**豁免每日限时**                        |
| 管理员    | 配置文件指定的地址，钱包签名登录后进入管理面板                      |

## 3. 用户使用指南

### 3.1 快速开始（5 步）

1. **安装插件**：Chrome 安装 [CCDAO Connector](https://chromewebstore.google.com/detail/ccdao-connector/fpondiojcgaollhcmjgpjmldjjkealjb)，解锁并授权
2. **连接钱包**：打开首页 → 「连接钱包开始使用」→ 用户中心 → 连接钱包
3. **首次签名**：第一次创建容器会弹出**签名确认**（验证地址归属），确认后自动开通
4. **进入 DSH**：用户中心 → 「🚀 进入 DSH」→ 打开你的专属实例
5. **（可选）申请不限时**：用户中心 → 🛡️ CWT 验证 → 「申请验证（插件签名）」→ 管理员审批通过后豁免限时

### 3.2 CWT 验证（免限时）

- 状态流转：`未申请 → 待审批 → 已批准（豁免）`，或 `被拒（可重申请）` / `已撤销（恢复限时）`
- **无注册时效**：批准即豁免、撤销即受限；出示 token 仅证明"当前持钥"
- 审批由管理员在管理面板完成

### 3.3 模型配置

- **官方**：DeepSeek 官方 API（默认，deepseek-v4-flash / v4-pro），可配置 API Key
- **自定义端点**：OpenAI 兼容端点，最多 20 个；支持「🔍 探测模型」一键拉取模型列表
- 保存需**钱包签名**；API Key 写入你的容器，端点/模型写入 settings.yaml，约 100ms 热生效
- 可随时「恢复默认」（清除所有自定义配置，同样需签名）

### 3.4 技能市场

- **浏览**：无需登录
- **安装**：需钱包签名 + **安装前确认弹窗**（风险提示 + 发布者 + 是否可被模型自动调用）
- **安全默认**：市场技能写入容器时强制 `disable-model-invocation: true`——**模型不会自动调用**，仅供你显式使用
- **我的技能**：导入本地 SKILL.md（需签名）、共享容器内技能到市场（名称需唯一，撞名自动提示改名）

### 3.5 容器管理

| 操作          | 效果                                                               |
| ------------- | ------------------------------------------------------------------ |
| 启动/停止容器 | 停止时**立即结算今日时长并保全剩余额度**（挂机不耗时长）；数据保留 |
| 重启 DSH 服务 | 安装插件后需重启生效                                               |
| 重置容器      | ⚠️ 删除所有数据和配置，不可恢复（双重确认）                        |

## 4. 管理员指南

### 4.1 登录（安全加固后）

- 管理面板登录 = **钱包签名**：插件弹窗签名一次性挑战（nonce），服务端验签后签发**随机会话**（12 小时，可退出吊销）
- 旧"报地址即登录"方式已废弃（一律 403）

### 4.2 管理功能

| 模块         | 功能                                                                               |
| ------------ | ---------------------------------------------------------------------------------- |
| 系统概览     | 总用户数 / 运行中 / 各配额层级计数                                                 |
| 用户列表     | 升级 / 降级配额、提权、强制下线、删除数据卷、彻底删除用户记录                      |
| 配额配置     | 三层（512M/1G/2G）资源展示                                                         |
| CWT 授权管理 | 待审批申请（批准/拒绝，附验签结果）、授权注册表（撤销）、审计记录（含 token 查看） |
| Docker 状态  | 运行中/未启动指示                                                                  |
| 地址合并     | 重复地址记录合并工具                                                               |

## 5. 安全特性（六面审计 → P0 全部闭环）

| 项              | 措施                                                                                                                                |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 管理员接管      | 签名登录 + 服务端随机会话（sha256 存储、12h TTL、可吊销）                                                                           |
| /connect 冒领   | 创建新容器必须**所有权签名**（一次性挑战防重放）；已有容器免签直连                                                                  |
| 拒绝服务（OOM） | 请求体上限（100KB）、全局/接口限流（429）、挑战池上限+清理                                                                          |
| 供应链注入      | 技能 `skills.autoInvoke=false` 默认强制 `disable-model-invocation`；安装前确认与风险提示；安装记录存 `installedHash` 防"有更新"误报 |
| 数据保护        | 敏感文件 0600 原子写；出示 token 单向时效（拒绝未来签发）；noopener                                                                 |
| 退出安全        | /leave 需鉴权；连接状态与限时联动                                                                                                   |

## 6. 部署与运维

### 6.1 架构

```
浏览器 (CCDAO 钱包)  ──HTTP──>  入口服务 :8090  ──Docker──>  用户容器 :31000+ (DSH)
                                    │
                              data/ (0600)  CWT 注册表 / 会话 / 技能 / 统计
```

### 6.2 部署（Linux + Docker + Node ≥18）

```bash
# 首次安装
SERVER_HOST=<IP> ./deploy/rsync-upload.sh
ADMIN_ADDRESS=<管理员地址> PUBLIC_HOST=<公网IP或域名> ./deploy/install.sh
```

### 6.3 数据与升级

- **保留旧数据**：上传自动排除 `data/ config.json state.json patches/`；`update.sh` 只更新代码
- **备份**：`sudo ./deploy/backup.sh`（+ `VOLUME_BACKUP=1` 连租户数据卷），保留最近 7 份
- **升级**：`sudo ./deploy/update.sh`（内网离线自动全量重建）；`systemctl restart dsh-multitenant`
- **回滚**：解包最近备份 + 重启

### 6.4 生产建议

- 租户端口段 31000-65535 避免直接暴露公网（内网/VPN 或 nginx + HTTPS + 访问控制）
- 建议 `RUN_USER=dsh`（非 root 运行入口服务）

## 7. 限制与路线图

- **当前限制**：单实例部署（多实例需共享存储扩展）；容器特权 SYS_ADMIN 暂未降权（待真机验证 bwrap）；正文内容无自动扫描（技能"未审核"标记、举报为 P1-10 待办）
- **路线图**：见 `docs/roadmap-next.md`——P1 纵深（密钥 argv 泄露、SSRF、IDOR、配额）→ P2 部署（HTTPS + Secure Cookie、CSP、写锁）→ 产品（AdminPanel 技能管理 UI、技能 zip 打包、插件市场）
