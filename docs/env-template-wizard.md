# 定格容器 · 分步引导方案（用户侧向导为主）

> 状态：待审方案（2026-10-27）。承接《环境模板方案 v2》——定格=镜像层+作者勾选随行包；
> 本文档回答"用户从头到尾按什么、看到什么、系统做什么、错了怎么办"。
> 视角排序：作者（定格者）→ 接收者 → 管理员（审核），附录给接口映射。

---

## 一、作者向导：定格我的环境（六步）

入口：用户中心 → 环境模板 → 【定格我的环境】按钮。
**资格门（2026-10-27 用户定式）：只有 cwt 持有者或管理员可定格**——定格是供应链
入口，模板被换用即作者代码进别人容器，开口权配给担责的人。判定收口
`credentialService.freezeAllowed(addr)`（isAdmSync ∪ async isExempt：快照未中
当场实查回填，刚批准的人不等水合）。被拒不产生上锁事故（容器照常用，只是不能
定格——这是授权门非访问门，fail-closed 正当）。
按钮点亮条件：本人容器正在运行（停着不能格——定格拍的是活环境的安静瞬间）。
不满足时按钮置灰 + 文案："容器未运行。连接一次容器后即可定格。"
无资格时入口文案："定格需要 CWT 或管理员凭证。〔申请 CWT〕"（链接现成申请通道）。
管理员代格通道（admin env-commit）天然满足（requireAdmin 即门槛）。

### 第 1 步 · 起个名字，写句介绍

| 屏幕要素             | 内容                                                                                    |
| -------------------- | --------------------------------------------------------------------------------------- |
| 环境名（必填）       | 小写字母/数字/连字符，如 `stock-trader`。规则即时校验（入镜像名，从严）                 |
| 一句话介绍（建议填） | 接收者卡片上看到的第一个东西。占位文案示例："装了 akshare + 我的看盘脚本，跑日线策略用" |
| 说明块               | "定格后先进草稿，管理员审核通过才公开。你带的东西只有你勾选的。"                        |

- 动作：〔下一步〕。名字重复允许（不同人同名不冲突，模板全名自带作者前缀）。
- 设计意图：介绍文案=审核的第一线索+接收者的选择依据，所以放在第一步而不是最后补。

### 第 2 步 · 勾选随行内容（本向导的心脏）

系统先调 `inventory` 拉三类清单（技能=平台台账、插件=实读卷、文件夹=一级分类统计），
页面分区展示：

```
▍软件与环境（镜像层）              不可勾选 · 自动包含
  将带走：apt 装的软件、/usr/local、/opt、/root 下你放的文件等
  [展开查看文件清单]（定格时生成的 manifest 预览，此处先给粗统计：约 N 项 / X MB）

▍技能（3 个已装）                  按条勾选，默认全不勾
  ☐ cwt-verify（平台仓库版）
  ☐ ticker-watch（平台仓库版）
  ☐ report-gen（平台仓库版）
  ⓘ 接收者拿到的将是平台仓库的当前版本，不是今天这份拷贝

▍插件（2 个）                      按条勾选，默认全不勾
  ☐ my-ticker.ui（12 KB · a1b2c3…）
  ☐ strategy-hook（3.4 KB · d4e5f6…）
  ⚠ 插件是你自己的代码，会原样公开给使用者——确认没有写死的密钥/账户

▍文件夹（工作区一级目录）           按目录勾选，默认全不勾
  ☐ 策略/（14 个文件 · 220 KB）
  ☐ 数据缓存/（1.2 GB）            ← 超单文件/总包上限时此条红显不可勾
  ☐ 私密持仓/（3 个文件）
     ⓘ 勾选即视为同意公开，管理员会看到文件内容摘要

▍偏好设置                          按项勾选，默认全不勾
  ☑ 界面主题/语言（脱敏白名单内）
  ▒ 模型与密钥设置 —— 永不可带（见下）

▍平台禁止外带（灰显区）             不可勾选，永远
  ▒▒ credentials/（密钥）
  ▒▒ sessions/（登录态）
  ▒▒ cookie/token 类
  文案："这部分即使勾了平台也不会带上——它等于把你的人钥匙发给别人。"

──────────────────────────────────────
随身体积合计：0 MB / 200 MB 上限 · 单文件 ≤50 MB · 条目 ≤200
```

- 交互纪律：**默认全不勾**（带走是例外，不是自动）；每勾一项体积合计实时更新；超限项红显并给原因。
- 贴心侦测（软提醒，不阻断）："你有 87 个文件在'数据缓存/'未勾选——它们不会被带走，需要吗？"（只提示一次/目录）。
- 全部不勾也允许进入下一步 = **纯镜像定格**（合法的"只带软件"形态）。
- 防手滑设计的原因：勾选制下"带什么"由作者决定，平台只保证"没勾的绝对不带、禁区永远不带"。

### 第 3 步 · 影响预览与知情确认

系统调 `dryRun` 定格（不碰任何东西，只回预算信息），页面展示：

```
将发生的事情：
 1. 你的容器停机约 15~60 秒（正在跑的会话会断，起来后可重连）
 2. 拍一张"软件层"快照（镜像 ~840 MB）
 3. 按你的勾选导出随行包（4 项 / 2.3 MB），清单如下
    [展开完整清单：文件路径+大小+哈希]
 4. 提交审核。通过前只有你和管理员可见。

 ☐ 我了解：审核通过后，以上勾选内容将对平台其他用户公开。
                              〔开始定格〕（未勾选时禁用）
```

- 正在使用容器的检测：若当前会话活跃，追加一句"检测到你有进行中的会话，建议先保存工作"——**不阻断**（绝不上锁）。
- 体积预检失败（镜像层超 2GB）：这一步直接红字告知"定格会被拒——可先清理非卷的大文件"，按钮保持禁用（拒绝发生在动手前，比格完再弃体面）。

### 第 4 步 · 执行中（进度可见）

五段进度条，每段实时状态（数据来自定格接口的阶段回报，前端轮询或 SSE——实现阶段定）：

```
● 停止容器…            ✓ 4s
● 定格镜像层…          ✓ 11s（840MB）
● 导出随行包…          进行中
○ 恢复你的容器…
○ 提交审核
```

- **任何一步失败**：页面诚实显示断在哪 + 固定尾话"你的容器已自动重新启动（或正在重启）"。系统侧保证：finally 必起回源容器、半成品（镜像/包）当场删除不留账。
- 失败不产生"半定格"：要么进第 5 步（草稿入册），要么世界无痕。

### 第 5 步 · 提交后：等审核

```
✓ 已提交：stock-trader（你的第 1 个模板，剩余额度 4/5）
 状态：草稿，等待管理员审核
 ⓘ 审核通过会在这里通知你；被驳回会附原因，你可以修改后重新定格一版。
 〔查看模板〕〔回到我的容器〕
```

- 额度用满 5 个：入口按钮处明说（下架旧的才能格新的——只减不增的额度版）。
- 驳回后的"重新定格"= 第 1 步重走（旧稿弃置即删，不存"改天再审"通道——防债务堆积，方案 v2 §9-3 拍板项）。

### 第 6 步 · 上架后：作者的持续管理

模板卡（用户中心"我的模板"区）：

```
stock-trader          已上架 · v20261027
 使用中：3 人 · 随身体积 2.3 MB
 〔下架〕〔重新定格一版〕
 ⓘ 下架后新的人不能再换用；已经在用的人不受影响（不会被踢回来）。
 ⓘ 每次重新定格=新的一次审核；建议先下架旧版。
```

- 作者**不能**改已上架模板的内容（改了就是另一次定格+另一次审核——模板不可变，digest 钉的语义在人这一层也成立）。

## 二、接收者向导（简述，PR4 UI 详设）

```
浏览列表（已上架的才出现）
  → 卡片：作者地址 · 介绍 · 基座版本（落后平台时黄条"基于旧版 DSH"）
         · 镜像大小 · "含作者技能 2、插件 1、文件 4 项"折叠清单
  → 〔换用此环境〕
  → dryRun 预览（两件事必须看清）：
       · "将停机约 X 秒"
       · "随行包装入时将有 1 个同名文件被覆盖：plugins/my-ticker.ui"（冲突清单）
       · 固定承诺行："你的密钥、登录态、工作区文件不会被改动或删除。"
  → 〔确认换用〕→ 进度（重建镜像 → 装包）→ 完成
  → 容器 tab 出现来源行：来自 <作者> 的 stock-trader（摘要 abc1234）
  → 反悔：〔恢复默认环境〕随时可点；已装进来的包文件不强制拆（你说了算）
```

## 三、管理员审核页（简述）

```
审核队列（draft 列表）
  → 审件页三栏：
     镜像层 manifest（路径清单+体积）
     随行包文件树（每项：路径/大小/哈希；文本类——插件源码、SKILL.md、勾选的
     代码文件——直接内嵌可读预览，超 200 行截断；二进制只列名）
     作者档案速览（其凭证状态/历史模板）
  → 〔通过并上架〕〔驳回（理由必填 → 反馈给作者）〕
  → 已上架模板：〔下架〕随时；〔代格〕对任意用户容器执行同款六步（压缩版：
     代格时勾选由管理员按 inventory 替作者决定——默认全不带，保守）
```

| 向导步骤                | 接口                                                                       | 现状                                                                                                |

账本增字段：`intro`（展示用）、`include`、`bundle`；状态机加 `rejected`（即弃：
删镜像+删包+留审计摘要）。
